# Personal Portfolio

Portfolio website repository for Emirosman Murtazayev.

## Repository Contents

This repository contains the built website: `index.html`, compiled JavaScript and CSS under `assets/`, images, and supporting static files.

It contains deployment assets rather than the original React source project. Changes to application components should be made in the source project and rebuilt before replacing the generated assets.

## Preview Locally

With Python installed, run this command from the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000. This previews static files; it does not reproduce every hosting or client-side routing behavior.
